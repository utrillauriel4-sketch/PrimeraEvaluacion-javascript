Ejercicio 1

Un estudiante realiza 4 exámenes, calcular el promedio de estos.

RESPUESTA — CÓDIGO JAVASCRIPT
const nota1 = Number(prompt("Ingrese la primera nota:"));
const nota2 = Number(prompt("Ingrese la segunda nota:"));
const nota3 = Number(prompt("Ingrese la tercera nota:"));
const nota4 = Number(prompt("Ingrese la cuarta nota:"));

const promedio = (nota1 + nota2 + nota3 + nota4) / 4;

console.log("Promedio:", promedio);

Ejercicio 5

Hallar el promedio de todos los elementos del arreglo. Entrada: [2, 6, 1, 8]. Salida: Promedio: 4.25.

RESPUESTA — CÓDIGO JAVASCRIPT
const numeros = [2, 6, 1, 8];

let suma = 0;

for (let i = 0; i < numeros.length; i++) {
    suma += numeros[i];
}

const promedio = suma / numeros.length;

console.log("Promedio:", promedio);
Ejercicio 6

De un arreglo de números, retornar la suma de todos los números pares. Entrada: [1, 2, 5, 8, 9, 12, 2, 3].

RESPUESTA — CÓDIGO JAVASCRIPT
const numeros = [1, 2, 5, 8, 9, 12, 2, 3];

let sumaPares = 0;

for (let i = 0; i < numeros.length; i++) {
    if (numeros[i] % 2 === 0) {
        sumaPares += numeros[i];
    }
}

console.log("Suma de pares:", sumaPares);

Ejercicio 10

Solicitar al usuario una calificación entre 1 y 10. Comprobar que esté en ese rango. Mostrar “reprobado” si es inferior a 6, “regular” si está entre 6 y 8, “bien” si es 9 y “excelente” si es 10.

RESPUESTA — CÓDIGO JAVASCRIPT

    console.log("Error: la calificación debe estar entre 1 y 10.");
} else if (calificacion < 6) {
    console.log("reprobado");
} else if (calificacion <= 8) {
    console.log("regular");
} else if (calificacion === 9) {
    console.log("bien");
} else {
    console.log("excelente");
}
Ejercicio 11

Crear un programa que solicite al usuario 2 números entre 1 y 50. Mostrar en consola los números del 1 hasta el 50 y añadir “¡Lotería!” solo al mostrar los números indicados por el usuario.

RESPUESTA — CÓDIGO JAVASCRIPT
const primerNumero = Number(prompt("Primer número (1-50):"));
const segundoNumero = Number(prompt("Segundo número (1-50):"));

if (
    primerNumero < 1 || primerNumero > 50 ||
    segundoNumero < 1 || segundoNumero > 50 ||
    isNaN(primerNumero) || isNaN(segundoNumero)
) {
    console.log("Error: los números deben estar entre 1 y 50.");
} else {
    for (let i = 1; i <= 50; i++) {
        if (i === primerNumero || i === segundoNumero) {
            console.log(i, "¡Lotería!");
        } else {
            console.log(i);
        }
    }
}
Ejercicio 12

Escriba un programa de JavaScript que itera enteros del 1 al 100. Para múltiplos de tres, imprimir “Fizz”; para múltiplos de cinco, “Buzz”; y para números múltiplos de tres y cinco, “FizzBuzz”.

RESPUESTA — CÓDIGO JAVASCRIPT

    if (i % 3 === 0 && i % 5 === 0) {
        console.log("FizzBuzz");

        console.log("Fizz");
    } else if (i % 5 === 0) {
        console.log("Buzz");
    } else {
        console.log(i);
    }
}
Ejercicio 13

Se les dará un bono por antigüedad a los empleados de una tienda. Si tienen 1 año, $100; 2 años, $200, y así sucesivamente hasta 5 años. Para más de 5 años, el bono será de $1000. Determinar el bono que recibirá un trabajador.

RESPUESTA — CÓDIGO JAVASCRIPT
const anios = Number(prompt("Ingrese los años de antigüedad:"));

let bono;

if (anios > 5) {
    bono = 1000;
} else {
    bono = anios * 100;
}

console.log("Bono:", "$" + bono);
Ejercicio 14

Un profesor tiene un salario inicial de $1500 y recibe un incremento de 10 % anual durante 6 años. ¿Cuál es su salario al cabo de 6 años? ¿Qué salario ha recibido en cada uno de los 6 años? Realice el programa utilizando el ciclo apropiado.

RESPUESTA — CÓDIGO JAVASCRIPT
let salario = 1500;

for (let anio = 1; anio <= 6; anio++) {
    salario = salario * 1.10;
    console.log("Año " + anio + ": $" + salario.toFixed(2));
}

console.log("Salario al cabo de 6 años: $" + salario.toFixed(2));

En una lista de palabras, el bibliotecario necesita saber cuál es la palabra más larga. Lista: ["manzana", "banana", "cereza", "uva", "fresa"].

Ejercicio 16

Un coleccionista tiene una caja con varias cartas. Algunas están numeradas del 1 al 10, pero hay cartas repetidas. ¿Cuántas cartas únicas tiene en total? Lista: [1, 2, 3, 4, 2, 3, 5, 6, 7, 8, 1, 9, 10, 10].

RESPUESTA — CÓDIGO JAVASCRIPT
let cartas = [1, 2, 3, 4, 2, 3, 5, 6, 7, 8, 1, 9, 10, 10];

let cartasUnicas = [];

for (let i = 0; i < cartas.length; i++) {
    if (!cartasUnicas.includes(cartas[i])) {
        cartasUnicas.push(cartas[i]);
    }
}

console.log("Cartas únicas:", cartasUnicas);
console.log("Cantidad de cartas únicas:", cartasUnicas.length);

Ejercicio 18

El programa educativo contempla: Course $4999 MXN mensual, Carrera $3999 MXN mensual y Master $2999 MXN mensual. Aplicar la beca correspondiente: Facebook 20 %, Google 15 %, Jesua 50 %. Mostrar el precio mensual con descuento y el gasto total según la duración: Course 2 meses, Carrera 6 meses, Master 12 meses.

RESPUESTA — CÓDIGO JAVASCRIPT
const programa = prompt("Elija: Course, Carrera o Master:").toLowerCase();
const beca = prompt("Beca: Facebook, Google o Jesua:").toLowerCase();

let precioMensual;
let meses;

if (programa === "course") {
    precioMensual = 4999;
    meses = 2;
} else if (programa === "carrera") {
    precioMensual = 3999;
    meses = 6;
} else if (programa === "master") {
    precioMensual = 2999;
    meses = 12;
} else {
    console.log("Programa no válido.");
}

let descuento = 0;

if (beca === "facebook") {
    descuento = 0.20;
} else if (beca === "google") {
    descuento = 0.15;
} else if (beca === "jesua") {
    descuento = 0.50;
}

if (precioMensual !== undefined) {
    const mensualConDescuento = precioMensual * (1 - descuento);
    const total = mensualConDescuento * meses;

    console.log("Pago mensual con descuento: $" + mensualConDescuento.toFixed(2));
    console.log("Total del programa: $" + total.toFixed(2));
}
Ejercicio 19

Crear un programa que solicite números. Si lo introducido es un número, guardarlo en un arreglo. Para terminar, ingresar el número 0. Finalmente mostrar la lista de números capturados.

RESPUESTA — CÓDIGO JAVASCRIPT
const numeros = [];

while (true) {
    const entrada = prompt("Ingrese un número (0 para terminar):");

    if (entrada === null) {
        break;
    }

    const numero = Number(entrada);

    if (isNaN(numero)) {
        console.log("Ingrese un número válido.");
        continue;
    }

    if (numero === 0) {
        break;
    }

    numeros.push(numero);
}

console.log("Números capturados:", numeros);
Ejercicio 20

Calcular el total a pagar según la distancia recorrida y los litros consumidos. Coche: 0.20 por km; moto: 0.10 por km; autobús: 0.5 por km. Si los litros están entre 0 y 100 se añade 5; si son mayores de 100 se añade 10. Total = (precio por kilómetro × kms recorridos) + extra.

RESPUESTA — CÓDIGO JAVASCRIPT
const vehiculo = prompt("Ingrese el vehículo: coche, moto o autobús").toLowerCase();
const kilometros = Number(prompt("Ingrese los kilómetros recorridos:"));
const litros = Number(prompt("Ingrese los litros consumidos:"));

let precioKilometro;

if (vehiculo === "coche") {
    precioKilometro = 0.20;
} else if (vehiculo === "moto") {
    precioKilometro = 0.10;
} else if (vehiculo === "autobús" || vehiculo === "autobus") {
    precioKilometro = 0.5;
} else {
    console.log("Vehículo no válido.");
}

if (precioKilometro !== undefined) {
    let extra;

    if (litros >= 0 && litros <= 100) {
        extra = 5;
    } else {
        extra = 10;
    }

    const total = (precioKilometro * kilometros) + extra;

    console.log("Total a pagar:", total);
}
